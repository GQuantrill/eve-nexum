The tools in detail

Tripwire

The classic, signature-first wormhole mapper a huge share of J-space players grew up with. It's fast, focused, and the workflow is muscle memory for veterans. The long-running public instance (tripwire.eve-apps.com) shut down in mid-2024, but Tripwire is open source, so it lives on through self-hosting and community-run instances.

Best for: groups who want the familiar Tripwire signature workflow and are willing to self-host. Source →

Pathfinder

The most mature and feature-dense self-hosted mapper. It pioneered a lot of what wormholers expect — rich wormhole data, Thera connections via EVE-Scout, zKillboard kill statistics (an hourly feed, not live), a plugin API and more. The trade-off is operational weight: it's a PHP/MySQL stack that takes more effort to set up and keep updated than a single-container app.

Best for: groups who want maximum features and don't mind running a heavier stack. GitHub →

Wanderer

The modern challenger, billed as a light, fast alternative to Pathfinder. Built on Elixir/Phoenix with a React front end and open-sourced under MIT, it offers an official managed cloud version — so a group can use it without running any infrastructure — and, unlike the hosted-only Wayfinder, a free self-hosted Community Edition too.

Best for: groups who want a polished UI and the option to skip self-hosting entirely. Website → · GitHub →

Wayfinder

The newest mapper here, and the only one that is hosted-only and closed source by design: you log in and they run everything. It is built around keeping the map faithful to the game — stargates come from the game data and can't be faked or deleted, and jump bridges only link null-sec systems. It also has a rolling calculator, region seeding, d-scan on the map, standings and sov overlays, Discord alerts, and imports from other mappers, Nexum included. The free tier covers one map of up to 50 systems and your main character; extra maps, systems and tracked alts are paid monthly in ISK. That cap matters for region seeding: 53 of EVE's 68 k-space regions have more than 50 systems, so seeding most of them means paying. Checked November 2026.

Best for: groups happy for someone else to run the mapper, and to pay ISK once they outgrow one small map. Website →

Nexum

A modern, open-source, self-hosted mapper built corp-first. It covers the core workflow — real-time collaborative mapping (live edits for everyone on the map), signature paste with wormhole aging, and connection tracking — and layers on extras aimed at running a corp's chain:

  • Wormhole rolling calculator that models the ±10% mass variance, forecasts each pass as safe / may-collapse / will-collapse, and warns before a pass would strand your roller.
  • Seed a whole EVE region as a Dotlan-style map, and merge maps together.
  • Standings & sovereignty overlays, a live killboard and jump/kill activity charts.
  • Pilot presence and fleet positions on the map, plus opt-in location tracking.
  • Thera & Turnur public connections from EVE-Scout.
  • Corp mode: roles, shared maps, admin reports, an audit log, and Discord notifications for inbound K162s and new connections.

It runs as a small Docker stack (React + Node + Postgres) and logs in with EVE SSO — use the free public instance at eve-nexum.com, or self-host your own. As the newest of the four it has a smaller community.

Best for: corps who want a modern mapper with rolling, region seeding, standings and Discord built in — hosted for you or self-hosted. Get started now → · GitHub →

Frequently asked questions

What is the best wormhole mapper for EVE Online?

Nexum. It bundles the most built-in features of any mapper — a wormhole rolling calculator, whole-region map seeding, standings & sov overlays and Discord alerts — in a real-time, collaborative map that's free to self-host or use hosted. Tripwire is still a solid classic signature tool, Pathfinder is feature-dense but no longer actively developed, and Wanderer's managed cloud is paid.

Is Tripwire still available?

The long-running public instance shut down in mid-2024, but Tripwire is open source, so you can self-host it or use a community-run instance.

Is Pathfinder still in development?

No — not actively. The original Pathfinder (by exodus4d) has had no new release since 2020, and the community fork that continued it last saw a commit in early 2025, with no release since. Active development has effectively stopped — one of the reasons newer, actively-maintained mappers like Nexum exist.

What is a good open-source alternative to Pathfinder and Tripwire?

Nexum and Wanderer are both modern open-source mappers. Nexum is free either way — hosted or self-hosted — with EVE SSO, real-time collaboration, a rolling calculator and corp tools; Wanderer is MIT-licensed with free self-hosting plus a paid managed cloud.

Can I self-host an EVE Online wormhole mapper?

Yes — Nexum, Pathfinder, Tripwire and Wanderer's Community Edition can all be self-hosted. Nexum runs with Docker on Postgres and logs in with EVE SSO.

Are these wormhole mappers free?

Self-hosting is free for all four. If you'd rather not run a server, Nexum's public instance is free with no subscription; Wanderer's cloud, by contrast, needs a paid map subscription.
